   spend flow. Rebase alongside current Claude RPG changes and verify other modes still work.
2. Real permitted PAD pack/atlas validates all five colours, opening cast, every generated chapter join and retained
   versions. Robots/source issues must be resolved, not waived by a green build or fake roster. Prepare/publish through
   existing private content process only with authorization; no workflow/env/infra or credential workaround.
3. All pure parsers, API/Dexie versions, atomic operation protocol, epoch takeover, receipt reconciliation and protected
   cutover are deployed-compatible. No API source-TS import that passes tests but fails Nest production startup.
4. Small sim evidence meets the settled envelope; pin any last coefficient adjustment in design/domain/sim/new decision.
   Record neutral/counter parties, all encounter colours, two-chapter PL,54/132gross, recipient allocation and extra
   same-style boss repeats. Don't bury decorative HP/unused skills behind an averaged clear rate.
5. Synthetic real-host end-to-end proof: roster→five party→map→battle→EXP/debt/material→Items/exchange→CL spend→real
   nodes/SP→reload/offline/reconnect. Include loss, abandon, replay, exact-once commit, rejected offline spend, content
   update mid-run and explicit takeover. Existing race/Farm/RPG/Friendship flows pass regression.
6. Dry-run preservation summary and recoverable backup path reviewed; unavailable/malformed/old pending state has
   documented recovery. No account migration before replacement content/readiness.
